Static Linux

download / source / ecosystem / matrix

building from source

clone the main repo and run the build script:

git clone https://codeberg.org/StaticLinux/rootfs
cd rootfs
sh build.sh

booting in qemu

qemu-system-x86_64 \
  -kernel linux-7.0.8/arch/x86/boot/bzImage \
  -initrd rootfs.cpio.gz \
  -append "console=ttyS0 init=/init" \
  -nographic

installing packages

use atlas to install packages:

atlas dash
atlas git

building packages

use hephaestus to build a port:

python3 hephaestus.py static-ports/shells/dash
