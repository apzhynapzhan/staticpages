building from source

clone the main repo and run the build script:

git clone https://codeberg.org/StaticLinux/ashigaru
cd ashigaru
sh build.sh

the build script will download sources, compile the kernel and busybox, and produce a bootable rootfs.

booting in qemu

qemu-system-x86_64 \
  -kernel linux-7.0.8/arch/x86/boot/bzImage \
  -initrd rootfs.cpio.gz \
  -append "console=ttyS0 init=/init" \
  -nographic

exit qemu with Ctrl+A then X.

installing packages

use atlas to install packages:

atlas dash
atlas git

building a port

each port needs a build.sh and pkg.toml:

static-ports/
  shells/
    dash/
      build.sh
      pkg.toml

build it with hephaestus:

python3 hephaestus.py static-ports/shells/dash

prometheus

init system written in Rust. mounts filesystems, sets hostname, seeds rng, brings up loopback, spawns getty.

hostname is read from /etc/hostname.

atlas

package manager written in Rust. verifies sha256, extracts tarballs to /.

atlas dash-0.5.12

hephaestus

package build system written in Python. reads pkg.toml, runs build.sh, strips and tarballs the output.

python3 hephaestus.py static-ports/shells/dash
