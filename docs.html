building from source

clone the main repo and run the build script:

git clone https://codeberg.org/StaticLinux/rootfs
cd rootfs
sh build.sh

the build script downloads sources, compiles the kernel and busybox, and produces a bootable rootfs.

booting in qemu

qemu-system-x86_64 \
  -kernel linux-7.0.8/arch/x86/boot/bzImage \
  -initrd rootfs.cpio.gz \
  -append "console=ttyS0 init=/init" \
  -nographic

exit qemu with Ctrl+A then X.

installing packages

sync the ports tree first:

ace fetch

then install by category/name:

ace install shells/dash
ace install vcs/git

remove a package:

ace remove shells/dash

list installed packages:

ace query

writing a port

each port lives under its category in static-ports:

static-ports/
  shells/
    dash/
      build.sh
      pkg.toml

pkg.toml format:

name = "dash"
version = "0.5.12"
description = "minimal POSIX shell"
category = "shells"
source = "http://gondor.apana.org.au/~herbert/dash/files/dash-0.5.12.tar.gz"
sha256 = "..."
binary = "dash-0.5.12/src/dash"
install = "/usr/bin/dash"

build.sh handles configure and make. ace downloads the source, verifies the hash, runs build.sh, strips the binary, and installs it.

to test a port locally:

ace install shells/dash

prometheus

init system written in Rust. mounts filesystems, sets hostname, seeds rng, brings up loopback, spawns getty.

hostname is read from /etc/hostname.

ace

package manager written in C. fully static, musl only. no runtime deps.

ace fetch            # sync ports tree
ace install <pkg>   # build and install
ace remove <pkg>    # uninstall
ace query [pkg]     # list or inspect

ports are fetched from ports.staticlinux.org. the ports tree mirrors the static-ports repo on every push.
