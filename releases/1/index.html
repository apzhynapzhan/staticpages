Static Linux/1: GNU's Gambit v0.1.0

The first release of Static Linux. Boots to a login prompt, mounts the essential filesystems, and brings up a working BusyBox environment with a custom Rust init.

What's included
  • Prometheus - a Rust init system with filesystem mounting, hostname, loopback, and getty
  • BusyBox 1.38.0 userland
  • Linux 7.0.12 kernel
  • Limine bootloader
  • curl and ace
Known limitations
  • No persistent storage
  • No package manager in this release
  • Serial and virtual console only
